JobScrape AI processing lifecycle

These diagrams separate deterministic collection and validation from local Ollama inference, and show where user review remains required before an application artifact is created.

1. Optional job-board discovery

flowchart LR

Lifecycle rules captured here

  • Python fetches and normalizes external pages; Ollama receives bounded evidence and returns structured JSON.
  • Invalid or unavailable AI output does not overwrite an existing job result. The processor retries where configured, records failures, and preserves the last valid data.
  • Fit Briefs are only generated for active jobs at or above AI_FIT_BRIEF_MIN_MATCH (75 by default).
  • Application Prep is queued by the dashboard but generated only by the separate Ollama-capable processor for eligible Move forward jobs.
  • AI suggestions remain grounded in resume and inventory evidence; a person chooses whether to approve resume changes or create an artifact.
